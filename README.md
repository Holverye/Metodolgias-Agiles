# CineCesde

Proyecto integrador del Técnico Laboral como Asistente en Desarrollo de Software, segundo semestre, CESDE. Submódulo: Metodologías Ágiles. Docente: Ing. Jorge E. Hernández.

## Problema y producto

La venta de boletería exclusivamente en el punto físico genera filas y dificulta consultar películas, horarios, salas y opciones de comida. CineCesde propone una página web para consultar la cartelera y simular la selección de una función, asientos y combos, generando un comprobante de demostración.

## Tecnologías

- HTML5: estructura de la página.
- CSS3: presentación y adaptación a celular y computador.
- JavaScript: filtros, selección de funciones, asientos, combos y cálculos.
- Markdown: documentación.
- Git y GitHub: control de versiones que realizará el equipo.
