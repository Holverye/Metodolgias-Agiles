# Visión del producto

## Identificación del problema

Según el documento original, el cine presenta baja asistencia y largas filas porque solo vende boletería físicamente. No dispone de un canal digital para consultar catálogo, disponibilidad de salas, cartelera, horarios y comida.

## Visión

Para las personas que desean organizar su visita al cine, CineCesde será una página web que reúna la cartelera y permita simular una compra. Facilitará escoger película, función, asiento y combo antes de obtener un comprobante de demostración.

## Objetivos verificables del prototipo

- Permitir consultar todas las películas de un conjunto de datos de ejemplo.
- Mostrar los horarios y el tipo de sala de una película seleccionada.
- Completar una simulación de compra con asientos y combos, mostrando el total en pesos colombianos.
- Mostrar una advertencia de simulación en el flujo y el comprobante.

La reducción de filas y el aumento de asistencia son beneficios esperados; no se han medido.

## Usuarios

Cliente o visitante: consulta información y utiliza el flujo de demostración. Personal del cine: referente del negocio; su módulo administrativo se deja para una fase posterior.

## Alcance inicial

Cartelera, detalle de película, funciones, asientos de ejemplo, combos, total y comprobante. Interfaz adaptable a móvil y computador. Datos locales de ejemplo en JavaScript.

## Límites

No se incluyen pagos reales, facturación, autenticación, servidor ni base de datos compartida. Una página local no garantiza disponibilidad simultánea entre clientes. El ticket será de demostración y no habilitará ingreso al cine.

La administración de cartelera y los puntos de fidelidad se documentan como evoluciones del prototipo. La nómina de empleados del modelo original queda fuera del alcance de esta página.
